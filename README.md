# WeChat-Echo

微信 4.x 多开免扫码登录工具。极简白设计，本地凭证管理，一次扫码永久复用。

## 功能

- **多开免扫码** — 同时运行最多 4 个微信 4.x 实例，首次扫码备份后免扫码登录
- **凭证管理** — 备份/切换/导出微信登录凭证，硬链接 + 软链接双模式
- **自动检测** — 头像缓存捕获、wxid 目录识别、进程窗口枚举
- **开机自启** — 注册表 Run 键，随系统启动

## 下载

从 [Releases](https://github.com/HugoLTZ/WeChat-Echo/releases) 下载最新 `WeChat-Echo.exe`，以管理员身份运行。

## 使用

1. **添加账号** — 在微信中扫码登录 → 点击「添加账号」→ 输入名称 → 点击「备份凭证」
2. **免扫码启动** — 点击账号卡片的 ▶ 按钮，微信直接登录
3. **多开** — 分别备份多个账号后，点击底部「登录」一键启动全部

## 技术栈

```
pywebview (Edge WebView2) + HTML/CSS/JS
         ↕  window.pywebview.api
      Python 业务层
    account / credential / launcher / process
```

## 开发

```bash
pip install -r requirements.txt
python main.py              # 需要管理员权限
```

### 打包

```bash
pip install pyinstaller
pyinstaller wechat_multi.spec
# → dist/WeChat-Echo.exe
```

## 注意

- 需要 Windows 10/11，微信 4.x
- 需要管理员权限（mklink 需要）
- 微信限制单机同时最多 4 个账号
- 凭证有时效性，过期后需重新扫码备份
