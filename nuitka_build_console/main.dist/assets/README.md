# 资源文件

## app_icon.ico
- 格式：ICO（Windows 图标格式）
- 尺寸：需包含 16x16、32x32、48x48、256x256 四档
- 用途：窗口标题栏 + 任务栏 + exe 文件图标
- 在线生成：https://www.icoconverter.com

## app_icon.png
- 格式：PNG（透明背景）
- 尺寸：512x512（等比缩放到其他尺寸）
- 用途：pywebview 窗口图标、安装包封面

## avatar_default.png
- 格式：PNG（可选透明）
- 尺寸：128x128
- 用途：账号无头像时的默认占位图
- 如不提供则显示首字母
